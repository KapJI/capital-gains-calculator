# PDF report design iterations

These PDFs are retained as immutable visual references. The dated files make typography, colour,
spacing, pagination, and wording changes easier to compare during future report redesigns.

- `2026-08-27-base-compatible.pdf`: base-LaTeX redesign before colour and optional Source Sans Pro
  were restored.
- `2026-08-27-colour-refresh.pdf`: colour refresh with Source Sans Pro when available and a
  base-LaTeX font fallback.

The current report remains at `../example_report.pdf`.
